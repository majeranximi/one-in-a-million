# One in a Million

**[Play in your browser](https://majeranximi.github.io/one-in-a-million/)** · [classic singleplayer version](https://majeranximi.github.io/one-in-a-million/singleplayer/)

A 3D browser racing game built with three.js. You swim as a sperm cell through the cervix, uterus and fallopian tube to reach the egg, racing against bots. The first to arrive wins, and the egg's shell hardens against everyone else.

## How to play

| Action | Controls |
|---|---|
| Steer | WASD, arrow keys or mouse |
| Burst (costs ATP, collect fructose to refill) | Space, Shift or left mouse button |
| Pause, sound | P or Esc, M |
| Phone | on-screen stick and burst button |

Each zone has its own hazard:

- **Cervix:** mucus walls slow you down unless you swim through the glowing holes.
- **Uterus:** a huge open space where white blood cells hunt the swimmers.
- **Fallopian tube:** the ciliary current pushes you back down the middle, so swim near the wall.
- **Ampulla:** the final sprint to the egg.

Swimming right behind a rival gives you extra speed, and the rare hyperactivation crystal lets you smash through obstacles.

## Multiplayer

Choose **Play online**, create a room and send the invite link or the 5-character code to friends. Up to 8 players race together, with 0, 5 or 11 bots.

- Players connect directly to the host's browser over WebRTC. [PeerJS](https://peerjs.com/)'s free public server only introduces them, so the game needs no server of its own.
- The host runs the bots, the white blood cells and the finish; every player steers their own swimmer locally, so controls never lag.
- The host's tab must stay open and in front during the race, because browsers pause pages in background tabs.
- If a player leaves mid-race, a bot takes over their swimmer.
- Some networks (strict corporate or mobile carrier NATs) block direct connections. The game then says so instead of hanging.

## Singleplayer version

The game before multiplayer is kept on the [`singleplayer`](https://github.com/majeranximi/one-in-a-million/tree/singleplayer) branch (tag `v1-singleplayer`) and is published at [/singleplayer/](https://majeranximi.github.io/one-in-a-million/singleplayer/). The current game still has the singleplayer race against bots as its main mode.

## Languages

The game is available in Czech, Italian, German, English, Polish, Slovak and Russian. English is the default. The first visit starts with a language picker, and the language can be changed later from the menu. Translations live in `src/i18n.js`, including a separate set of bot names for each language.

## Running locally

```bash
npm install
npm run build
npm start
```

Then open http://localhost:8123. The models are embedded in `dist/game.js`, so `dist/index.html` and `dist/game.js` are all the game needs.

## Development

- `npm run build` builds `dist/` from `src/` and `public/models/` (the models go into the bundle).
- `npm run models` converts the downloaded models in `assets/raw/` into `public/models/`.
- `npm run sim` runs races without a browser and prints the balance of each difficulty level.
- `npm run deploy` builds the game and publishes it to GitHub Pages, together with the singleplayer branch at `/singleplayer/`.
- Adding `?autopilot=1` to the URL hands control to a bot. Records are not saved in that mode.
